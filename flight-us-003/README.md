# Flight US 003

Flight US 003 is the couples anniversary mode for Selfection. It is a private, page by page reflection game designed for one laptop or iPad passed between two partners, with full iPhone adaptation.

## Run locally

Serve this directory through any static web server and open `index.html`. Opening the file directly also works, but offline installation requires a secure hosted origin such as GitHub Pages.

## GitHub Pages

Publish this directory at `flight-us-003/` inside the Selfection repository. Its expected address is:

`https://benorwho.github.io/Selfection/flight-us-003/`

Open it once while online and wait for the Ready Offline status before relying on it without a connection.

## Privacy

No answers are transmitted. The default storage mode uses the current browser tab. Optional device storage uses local browser storage and is not encrypted.

Photo previews remain in memory for the current session. They are not included in saved browser data or text exports.
